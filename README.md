# VitrinAI Digital Studio

Türkiye'deki işletmeler için dijital ürünler kuran bir stüdyo: işletmeye özel web
siteleri, Türkçe konuşan AI resepsiyonist, mobil uygulamalar ve yapay zeka
entegrasyonları. Fikri alır; tasarımı, yazılımı ve içeriği üretip yayına alır.

Bu hesap, stüdyonun geliştirdiği ürünlerin kaynak kodunu barındırır.
